# ifgame

A Clojure library for writing interactive fiction games, similar to [Inform 6](https://www.inform-fiction.org).
Includes an example game that is Heidi, which you will find in the [Inform Beginner's Guide](https://www.inform-fiction.org/manual/about_ibg.html).

## Installation

Just clone the repo.

## Usage

The project uses leiningen. Just just `lein run`.
